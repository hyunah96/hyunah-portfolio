## `IEnumerable`, `IEnumerable<T>` 

> `IEnumerable` / `IEnumerable<T>`는 **순회 가능한 컬렉션의 공통 규약**이다.
>  LINQ는 이 위에서 **쿼리(Where/Select 등)를 연결**해 데이터를 다룬다.  

### `IEnumerable` (비제네릭)
- `foreach`가 꺼내는 값이 **무조건 `object`이다.**
- 그래서 원래 타입으로 쓰려면 **캐스팅이 필요**하고, 타입이 섞이면 런타임 에러가 날 수 있다.
- 값 타입(`int` 등)은 `object`로 다룰 때 **박싱/언박싱**이 발생할 수 있다.
```csharp
using System;
using System.Collections;

class Program
{
    static void Main()
    {
        IEnumerable list = new ArrayList { 1, 2, 3 };

        foreach (object item in list)
        {
            int n = (int)item; 
		    Console.WriteLine(n);
        }
    }
}
```
### `IEnumerable<T>` (제네릭)
- `foreach`가 꺼내는 요소가 `T` 타입으로 나오기 때문에 **캐스팅이 필요 없고 타입이 안정적이다.**
- LINQ는 보통 `IEnumerable<T>` 위에서 동작한다.
```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        IEnumerable<int> nums = new List<int> { 1, 2, 3 };

        foreach (int n in nums)
        {
            Console.WriteLine(n);
        }
    }
}
```
### LINQ 지연 실행(Deferred Execution)
- `Where`, `Select` 같은 LINQ 메서드는 **바로 실행되지 않고**, 쿼리 정의만 만들어 둔다.
- 실제 실행은 **열거** 가 일어나는 순간에 된다.
    - `foreach` 할 때
    - `ToList()`, `ToArray()`, `Count()` 같은 **즉시 실행** 메서드를 호출할 때
```csharp
using System;
using System.Linq;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        var nums = new List<int> { 1, 2, 3, 4, 5 };

        var query = nums.Where(n => n % 2 == 0); // 여기서는 아직 실행 X (지연)

        nums.Add(6); // 원본 변경

        foreach (var n in query) // 여기서 실행 O (열거 순간)
        {
            Console.WriteLine(n); // 2, 4, 6 출력
        }
    }
}
```
#### 실행 순서
##### LINQ 쿼리 만들기 (아직 실행 안 됨)
```csharp
var query = nums.Where(n => n % 2 == 0);
```
- `query`는 **짝수만 골라내는 파이프라인**
- `Where`는 **결과를 바로 계산해서 리스트로 만들어 주는 게 아니다.** 
##### foreach 시작 (열거)
```csharp
foreach (var n in query)
{
    Console.WriteLine(n);
}
```
- `foreach`가 시작되면 `query`가 원본 `nums`를 순회한다.
##### 왜 이런 동작이 지연 실행인가?
- `Where()` 호출 시점에는 **계산(필터링)을 안 하고** `foreach` 같은 열거가 시작되는 시점에 **그때 계산**하기 때문이다.
### 즉시 실행(Immediate Execution)
- 지연 실행을 **지금 바로 결과로 만들어 버리는 것**
- 대표적으로 `ToList()`, `ToArray()`를 호출하면 그 시점에 결과가 고정된다.
```csharp
using System;
using System.Linq;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        var nums = new List<int> { 1, 2, 3, 4, 5 };

        var list = nums.Where(n => n % 2 == 0).ToList(); // 즉시 실행되어 결과 고정
        nums.Add(6);

        foreach (var n in list)
        {
            Console.WriteLine(n); // 2, 4만 출력 
                                  // (즉시 실행되었기 때문에 6은 들어오지 않는다)
        }
    }
}
```
