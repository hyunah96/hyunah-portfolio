## 상속(Inheritance), 합성(Composition)

> **상속은 is-a(~이다) 관계**, **합성은 has-a(~을 가진다) 관계**로 객체를 재사용하는 방법이다.  

---

### 상속(Inheritance)
- **기존 클래스를 확장**해서 기능을 물려받는 방식이다. (부모 클래스의 멤버(필드, 메서드)를 자식 클래스가 물려받아 재사용하는 객체지향 개념)
- 공통 기능을 재사용하기 쉽고, **다형성(override)** 로 동작을 바꿀 수 있다.
- 단점: 부모/자식이 강하게 엮여서 **결합도가 높아지고**, 부모 변경이 자식에 영향을 주기 쉽다.
```csharp
class Animal
{
    public virtual void Speak() => Console.WriteLine("...");
}

class Dog : Animal
{
    public override void Speak() => Console.WriteLine("멍멍");
}

class Program
{
    static void Main()
    {
        Animal a = new Dog();
        a.Speak();             // 멍멍
    }
}
```
### 합성(Composition)
- 다른 객체를 **멤버로 가지고(has-a)** 그 객체에게 일을 **위임하는 방식**이다.
- 필요한 기능만 조립해서 쓰므로 **유연하고 변경에 강하다.**
- 런타임에 구성 요소를 바꿀 수도 있어 테스트, 확장에 유리하다.
```csharp
interface ILogger
{
    void Log(string message);
}

class ConsoleLogger : ILogger
{
    public void Log(string message) => Console.WriteLine(message);
}

class FileLogger : ILogger
{
    public void Log(string message) => Console.WriteLine($"[FILE] {message}");
}

class OrderService
{
    private readonly ILogger _logger; // has-a

    public OrderService(ILogger logger)
    {
        _logger = logger;
    }

    public void CreateOrder()
    {
        _logger.Log("주문 생성!");
    }
}

class Program
{
    static void Main()
    {
        var service1 = new OrderService(new ConsoleLogger());
        service1.CreateOrder();

        var service2 = new OrderService(new FileLogger());
        service2.CreateOrder();
    }
}
```
**작동 순서**
- `new ConsoleLogger()` 실행 → `ConsoleLogger` 객체 1개 생성
    
- 그 객체가 `OrderService` 생성자 인자로 들어감
    →`new OrderService("이부분")`
- `new OrderService(logger)` 실행 → `OrderService` 객체 1개 생성
- 생성자 내부에서 `_logger = logger;` 실행  
    → `_logger`가 `ConsoleLogger`를 가리키게 됨
- `Console.WriteLine("주문 생성!")` 출력
