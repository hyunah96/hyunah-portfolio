### 파일 I/O란?
- 파일 I/O는 **파일(File)** 에서 데이터를 **읽고(Read)**, **쓰는(Write)** 작업을 말한다.  
- C#에서는 `System.IO.File` 클래스로 간단하게 텍스트 파일을 읽고 쓸 수 있다.
#### 경로
#### `@`
- 백슬래시`\`를 이스케이프 처리 안 하고 그대로 쓰게 해준다.
- 가독성이 좋아서 많이 사용한다.
```csharp
string path = @"C:\Temp\sample.txt";
```
### `\\` (escape)

```csharp
string path = "C:\\Temp\\sample.txt";
```
#### `File.ReadAllText(path)`
- 파일 전체를 **한 번에** 읽어서 `string`으로 반환한다.
- 파일이 없으면 `FileNotFoundException` 예외 발생 
- 경로가 잘못되면 `DirectoryNotFoundException` 예외 발생
```csharp
using System;
using System.IO;

string path = @"C:\Temp\sample.txt";

string text = File.ReadAllText(path);
Console.WriteLine(text);
```
**예외 처리 기본 패턴**
- 파일 I/O는 `try-catch`를 자주 쓴다.
```csharp
using System;
using System.IO;

try
{
    string path = @"C:\Temp\sample.txt";
    string text = File.ReadAllText(path);
    Console.WriteLine(text);
}
catch (Exception ex)
{
    Console.WriteLine($"파일 처리 실패: {ex.Message}");
}
```
#### `File.WriteAllText(path, text)`
- 지정 경로에 파일이 없으면 **새로 생성한다.**
- 파일이 있으면 기존 내용을 **전부 덮어쓴다.(Overwrite)**
```csharp
using System.IO;

string path = @"C:\Temp\sample.txt"; // 경로
string content = "Hello File I/O!";  // 내용

File.WriteAllText(path, content);
```
#### `File.AppendAllText(path, text)`
- 지정 경로에 파일이 없으면 **새로 생성한다.**
- 파일이 있으면 기존 내용 뒤에 내용을 **뒤에 추가한다.**
```csharp
using System.IO;

string path = @"C:\Temp\log.txt";

File.AppendAllText(path, "내용을 추가합니다");
```
#### `File.Exists(path)`
- **파일 존재를 확인한다.**
- 읽기 전에 체크하면 예외를 줄일 수 있다.
```csharp
using System;
using System.IO;

string path = @"C:\Temp\sample.txt";

if (File.Exists(path))
{
    string text = File.ReadAllText(path);
    Console.WriteLine(text);
}
else
{
    Console.WriteLine("파일이 없습니다.");
}
```
#### `Directory.CreateDirectory`
- 폴더를 생성한다.
```csharp
using System.IO;

string dir = @"C:\Temp";
string path = Path.Combine(dir, "sample.txt");

Directory.CreateDirectory(dir); // 이미 있으면 폴더 생성 안 함
File.WriteAllText(path, "안녕하세요.");
```
**참고사항** <br>
`Path.Combine`은 경로 문자열을 안전하게 합쳐주는 기능이다. <br>
문자열로 직접 합치면 실수가 자주 일어나는데, `Path.Combine`은 알아서 처리해준다.<br>
**실수 케이스 1 : 슬래시 없음**
```csharp
string dir = @"C:\Temp";
string path = dir + "sample.txt"; // C:\Tempsample.txt (슬래시 없음 경로 오류)
```
**실수 케이스2 : 슬래시 중복**
```csharp
string dir = @"C:\Temp\";
string path = dir + @"\sample.txt"; // C:\Temp\\sample.txt (슬래시 중복 경로 오류)
```
`Path.Combine` **알아서 처리**
```csharp
string dir1 = @"C:\Temp";
Console.WriteLine(Path.Combine(dir1, "sample.txt")); // C:\Temp\sample.txt
```
