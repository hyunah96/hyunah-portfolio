### `for`

- **몇 번 반복할지**가 명확할 때 사용한다.

```csharp
for (int i =0; i <5; i++)
{
    Console.WriteLine(i);
}
```

### 1부터 50까지 숫자 중에서 3의 배수만 출력

```csharp
static void Main(string[] args)
{
    for(int i =1; i<=50; i++)
    {
        if(i % 3 == 0)
        { 
	        Console.WriteLine(i);
        }
    }
}
```

### `while`

- 조건이 **true**인 동안에만 **반복**되며 false면 실행되지 않는다.

```csharp
int i =0;
while (i<5)
{
    Console.WriteLine(i);
    i++;
}
```

### 숫자들의 합 출력

```csharp
static void Main(string[] args)
{
    // while
    //사용자에게 계속 숫자를 입력받다가, 0을 입력하면 반복을 종료하고
    //그동안 입력한 숫자들의 합(sum) 을 출력

    int sum = 0;
    while (true) {
        Console.WriteLine("숫자를 입력해주세요");
        int.TryParse(Console.ReadLine(), out int inputNum);
        sum += inputNum;

        if (inputNum == 0)
        { 
            Console.WriteLine($"그동안 입력한 숫자들의 합 {sum}");
            break;
        }
    }
}
```

### `do while`

- 최소 **1번은 무조건 실행**하며 실행 후에 조건을 검사한다.
- **do 블록 먼저 1번 실행 → while(조건) 검사** 조건이 **true**면 다시 **do 블록 실행**
- 조건이 **false면** 반복 종료

```csharp
int i =0;
do
{
    Console.WriteLine(i);
    i++;
}while (i <5);
```

### 숫자들의 합 출력

```csharp
static void Main(string[] args)
{
    //do while
    //사용자에게 계속 숫자를 입력받다가, 0을 입력하면 반복을 종료하고
    //그동안 입력한 숫자들의 합(sum) 을 출력
    int sum = 0;
    int inputNum;
    Console.WriteLine("숫자를 입력해주세요");
    do
    {
        int.TryParse(Console.ReadLine(), out inputNum);
        if (inputNum != 0)
            sum += inputNum;
    }
    while (inputNum != 0);
Console.WriteLine($"그동안 입력한 숫자들의 합 {sum}");
}
```

### `foreach`

- **배열/리스트** 같은 자료구조의 **컬렉션 요소**를 **하나씩 순회할** 때 사용한다.

```csharp
int[] nums = {1,2,3};

foreach (int num in nums)
{
    Console.WriteLine(num);
}
```

### `break` 반복문 즉시 종료

```csharp
for (int i =0; i <10; i++)
{
		if (i ==5)
			break;
		Console.WriteLine(i);
}
```

### `continue` 이번 반복만 건너뛰고 다음 반복으로

- `i == 2`가 되면 `continue;`가 실행되고 그 아래 `Console.WriteLine(i);`는 **실행되지 않는다.**
- 그리고 for문의 증감식 `i++`로 가서 **다음 반복을 수행한다.**

```csharp
for (int i =0; i <5; i++)
{
		if (i ==2)
			continue;
		Console.WriteLine(i);
}
```
