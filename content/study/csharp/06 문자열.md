### 문자열(string)

### Trim()
- 앞/뒤 공백 제거
```csharp
"  hello  ".Trim();  // "hello"
```

#### TrimStart(), TrimEnd()
- `TrimStart()` 앞 제거
- `TrimEnd()`    뒤 제거
```csharp
"  hello  ".TrimStart(); // "hello  "
"  hello  ".TrimEnd();   // "  hello"
```
#### 특정 문자 제거
- 공백(' ')만이 아니라 `!`, `@`, `#` 같은 **특수문자도 제거된다.**

```csharp
"---hello---".Trim('-'); // "hello"
"00-123-00".Trim('0');   // "-123-"

string s = "!!!hello!!!";
Console.WriteLine(s.Trim('!')); // "hello"

string t = "@@@hello!!";
Console.WriteLine(t.Trim('@', '!')); // "hello"
```
### Split()
- 구분자로 잘라서 `string[]` 배열을 만든다.
```csharp
string data = "A,B,C";
string[] arr = data.Split(',');
```

#### 공백 제거
- `Split()`을 사용하여 구분자 기준으로 문자열을 잘라도, 각 요소의 앞, 뒤 공백은 자동으로 제거되지 않는다.
- 그래서 각 요소를 `Trim()`으로 정리한 뒤 배열로 만들기 위해 아래처럼 사용한다.
```csharp
string data = "A, B,   C";
var arr = data.Split(',')
              .Select(x => x.Trim())
              .ToArray();
// ["A","B","C"]
```

**동작 설명**
- `var arr = data.Split(',')` → `,` 기준으로 잘라서 문자열 배열 `arr`을 만든다.
- `Select(x => x.Trim())` → 각 요소를 `x`로 지정하여 `x.Trim()`으로 앞/뒤 공백을 제거한다.
- `ToArray()` → 새 묶음을 진짜 배열(`string[]`)로 변환해서 최종`arr`에 담는다.

#### 빈 항목 제거 옵션
- `StringSplitOptions.RemoveEmptyEntries`는 결과에 생긴 빈 문자열`""` 항목을 제거해준다.
- 빈 문자열`""`들이 빠지고 `"A"`, `"B"`만 남는다.
```csharp
string s = "A,,B,";
var arr1 = s.Split(','); 
// ["A", "", "B", ""]

var arr2 = s.Split(',', StringSplitOptions.RemoveEmptyEntries);
// ["A", "B"]
```
### Replace()

#### 문자열(string) 치환
- 특정 문자열을 다른 문자열로 바꾸어 새 문자열을 만들어 준다.
- `"hello world"` 안에서`"world"`라는 부분을 `"C#"`로 바꾸어 **새 문자열로 반환**한다.
```csharp
"hello world".Replace("world", "C#"); // "hello C#"
```
#### 문자(char) 치환
- 원본 문자열 `"1-2-3"` 안에서 `'-'`(하이픈) 문자를 `'/'` 문자로 바꾼 **새 문자열**을 만든다.
```csharp
string result = "1-2-3".Replace('-', '/');
// result: "1/2/3"
```
### 대소문자 변환
- `ToLower()`,`ToUpper()` 대소문자 변환 메서드이다.
```csharp
"AbC".ToLower(); // "abc"
"AbC".ToUpper(); // "ABC"
```

### Contains()
- 문자열 안에 특정 문자열(또는 문자)이 들어있는지 확인한다.
```csharp
string email = "hyuna.kim@gmail.com";
bool hasGmail = email.Contains("gmail");
// hasGmail: true
```

#### 대소문자 무시하고 비교
- `StringComparison.OrdinalIgnoreCase` 문자열을 비교할 때 **대소문자 무시** 비교 방식 옵션
```csharp
string userInput = "HeLLo world";
bool hasHello = userInput.Contains("hello", StringComparison.OrdinalIgnoreCase);
// hasHello: true

```
### IndexOf()
-  문자열 내부에서 특정 문자열이 **처음 등장하는 위치(index)** 를 반환한다.
- **찾지 못하면 `-1`** 을 **반환**한다.  즉, `-1` 여부로 존재하는지, 안하는지도 판별 가능하다.
```csharp
string fileName = "report_2025_final.pdf";
int pos = fileName.IndexOf("_final");
// pos: 11
```
```csharp
string text = "Hello C#";
int pos = text.IndexOf("Java");
// pos: -1
```
### StartsWith()
- 문자열이 특정 문자열로 **시작하는지** 검증할 때 사용한다.
```csharp
string url = "https://naver.com";
bool isHttps = url.StartsWith("https://");
// isHttps: true
```
```csharp
string command = "/help";
bool isCommand = command.StartsWith("/");
// isCommand: true
```
### EndsWith()
- 문자열이 특정 문자열로 **끝나는지** 검증할 때 사용한다.
```csharp
string doc = "resume.docx";
bool isPdf = doc.EndsWith(".pdf");
// isPdf: false
```

**예제코드**
```csharp
string file = "report_final_2025.pdf";

bool ok =
    file.EndsWith(".pdf", StringComparison.OrdinalIgnoreCase) &&
    file.Contains("final", StringComparison.OrdinalIgnoreCase);
// ok: true
```
### Substring()
- `Substring(startIndex, length)` : 시작 위치 + 길이로 잘라내기
- `startIndex` : 0부터 시작하는 인덱스
- `length` : 잘라낼 문자 개수
```csharp
string s = "ABCDEFG";
string r = s.Substring(2, 3);
// r: "CDE"
```
```csharp
string s = "ABCDEFG";
string r = s.Substring(0, 3);
// r: "ABC"
```
### 범위 연산자
- `[start..end]` → `start`부터 `end`미만
- `[..end]` → 처음부터 `end`까지
- `[start..]` → `start`부터 끝까지
```csharp
string s = "ABCDEFG";

string r1 = s[2..5];
// r1: "CDE"  (2 이상 5 미만)

string r2 = s[..3];
// r2: "ABC"  (처음부터 3 미만)

string r3 = s[4..];
// r3: "EFG"  (4부터 끝까지)
```


### 문자열 합치기

#### Concat()
- **구분자 없이** 여러 조각을 그대로 붙여서 새로운 문자열을 만든다.
```csharp
string r = string.Concat("A", "B", "C");
// r: "ABC"
```
```csharp
string first = "2025";
string second = "Final";
string r = string.Concat(first, "_", second);
// r: "2025_Final"
```
#### Join()
- 배열, 리스트 같은 여러 문자열 사이에 **구분자**를 넣어서 합친다.
```csharp
var arr = new[] { "A", "B", "C" };
string r = string.Join(",", arr);
// r: "A,B,C"
```
```csharp
var parts = new[] { "report", "2025", "final" };
string r = string.Join("_", parts);
// r: "report_2025_final"
```


### 문자열 비교
#### 기본 비교(`==`)
- 기본 비교는 대소문자를 구분한다.
- `==`는 보통 **null 비교에 안전**하다.
- 대소문자 무시 비교 방식 옵션을 줄 수 없다.
```csharp
string a = "abc";
string b = "ABC";

bool r = (a == b);
// r: false
```

#### Equals()
- Equals는 대소문자를 구분한다.
- **null이면 예외**가 발생한다.
- **대소문자 무시** 비교 방식 옵션 `StringComparison.OrdinalIgnoreCase`
```csharp
"abc".Equals("ABC"); // false

string input = "PDF";
bool isPdf = input.Equals("pdf", StringComparison.OrdinalIgnoreCase);
// isPdf: true
```

### 문자열 검사

#### `IsNullOrEmpty`
- **null + "" 은 true**
```csharp
string a = null;
string b = "";
string c = "   ";
string d = "hi";

bool r1 = string.IsNullOrEmpty(a); // true  (null)
bool r2 = string.IsNullOrEmpty(b); // true  ("")
bool r3 = string.IsNullOrEmpty(c); // false ("   " 공백은 내용이 있다고 봄)
bool r4 = string.IsNullOrEmpty(d); // false ("hi")
```
#### `IsNullOrWhiteSpace`
- **null + "" + " "공백 값까지 true**
```csharp
string a = null;
string b = "";
string c = "   ";
string d = "\t\n";   // 탭 + 줄바꿈
string e = " hi ";

bool r1 = string.IsNullOrWhiteSpace(a); // true  (null)
bool r2 = string.IsNullOrWhiteSpace(b); // true  ("")
bool r3 = string.IsNullOrWhiteSpace(c); // true  ("   " 공백)
bool r4 = string.IsNullOrWhiteSpace(d); // true  (탭, 줄바꿈)
bool r5 = string.IsNullOrWhiteSpace(e); // false (" hi " 글자가 있음)
```
