### 문자열(string)

#### Trim()
- 앞/뒤 공백 제거
```csharp
"  hello  ".Trim();  // "hello"
```

#### TrimStart(), TrimEnd()
- `TrimStart()` 앞 제거
- `TrimEnd()`    뒤 제거
```csharp
"  hello  ".TrimStart(); // "hello  "
"  hello  ".TrimEnd();   // "  hello"
```
#### 특정 문자 제거
- 공백(' ')만이 아니라 `!`, `@`, `#` 같은 **특수문자도 제거된다.**

```csharp
"---hello---".Trim('-'); // "hello"
"00-123-00".Trim('0');   // "-123-"

string s = "!!!hello!!!";
Console.WriteLine(s.Trim('!')); // "hello"

string t = "@@@hello!!";
Console.WriteLine(t.Trim('@', '!')); // "hello"
```
### Split()
- 구분자로 잘라서 `string[]` 배열을 만든다.
```csharp
string data = "A,B,C";
string[] arr = data.Split(',');
```

#### 공백 제거
```csharp
string data = "A, B,   C";
var arr = data.Split(',')
              .Select(x => x.Trim())
              .ToArray();
// ["A","B","C"]
```


### ✅ 빈 항목 제거 옵션

`string s = "A,,B,"; var arr1 = s.Split(',');  // ["A", "", "B", ""]  var arr2 = s.Split(',', StringSplitOptions.RemoveEmptyEntries); // ["A", "B"]`

## 4) 치환: Replace()

### ✅ 문자열 치환

`"hello world".Replace("world", "C#"); // "hello C#"`

### ✅ 문자 치환(char)

`"1-2-3".Replace('-', '/'); // "1/2/3"`

> Replace도 “원본 변경 X, 새 문자열 반환”.

## 5) 대소문자 변환

`"AbC".ToLower(); // "abc" "AbC".ToUpper(); // "ABC"`

> 한국어/터키어 등 문화권 이슈가 있을 수 있어서 서버/로그 등에서는 보통 `ToUpperInvariant()` 같은 것도 씀(기초 단계에서는 “있다 정도”만 기억).

## 6) 포함/검색: Contains, IndexOf, StartsWith, EndsWith

`string s = "Hello C#";  s.Contains("C#");      // true s.StartsWith("He");    // true s.EndsWith("#");       // true s.IndexOf("C#");       // 6 (없으면 -1)`

### ✅ 대소문자 무시하고 비교(실무에서 엄청 씀)

`s.Contains("hello", StringComparison.OrdinalIgnoreCase); // true`

---

## 7) 부분 추출: Substring / 범위

`string s = "ABCDEFG"; s.Substring(2, 3); // "CDE" (시작인덱스 2, 길이 3)`

### ✅ C# 범위 연산자 (가능하면 이게 편함)

`string s = "ABCDEFG"; s[2..5];  // "CDE" (2 이상 5 미만) s[..3];   // "ABC" s[4..];   // "EFG"`

## 8) 문자열 합치기: +, string.Concat, string.Join

### ✅ + (간단할 때)

`string r = "A" + "B";`

### ✅ Join (배열/리스트를 구분자로 합칠 때 최강)

`var arr = new[] { "A", "B", "C" }; string r = string.Join(",", arr); // "A,B,C"`

## 9) 문자열 비교: == vs Equals, StringComparison

`string a = "abc"; string b = "ABC";  (a == b); // false  a.Equals(b, StringComparison.OrdinalIgnoreCase); // true`

> 비교는 습관적으로 `StringComparison.OrdinalIgnoreCase` 기억해두면 실수 확 줄어.

## 10) 문자열 검사: IsNullOrEmpty / IsNullOrWhiteSpace

`string s1 = null; string s2 = ""; string s3 = "   ";  string.IsNullOrEmpty(s1);      // true string.IsNullOrWhiteSpace(s3); // true (공백만 있어도 true)`

## 11) 문자열 포맷팅: 보간(Interpolation) / Format

### ✅ 가장 많이 쓰는 방식: `$""`

`string name = "Hyuna"; int age = 25; string msg = $"{name} / {age}";`

### ✅ 숫자/날짜 포맷도 가능

`double v = 12.3456; string s = $"{v:F2}"; // "12.35"`
