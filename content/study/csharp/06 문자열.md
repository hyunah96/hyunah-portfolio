### 문자열(string)

### Trim()
- 앞/뒤 공백 제거
```csharp
"  hello  ".Trim();  // "hello"
```

#### TrimStart(), TrimEnd()
- `TrimStart()` 앞 제거
- `TrimEnd()`    뒤 제거
```csharp
"  hello  ".TrimStart(); // "hello  "
"  hello  ".TrimEnd();   // "  hello"
```
#### 특정 문자 제거
- 공백(' ')만이 아니라 `!`, `@`, `#` 같은 **특수문자도 제거된다.**

```csharp
"---hello---".Trim('-'); // "hello"
"00-123-00".Trim('0');   // "-123-"

string s = "!!!hello!!!";
Console.WriteLine(s.Trim('!')); // "hello"

string t = "@@@hello!!";
Console.WriteLine(t.Trim('@', '!')); // "hello"
```
### Split()
- 구분자로 잘라서 `string[]` 배열을 만든다.
```csharp
string data = "A,B,C";
string[] arr = data.Split(',');
```

#### 공백 제거
- `Split()`을 사용하여 구분자 기준으로 문자열을 잘라도, 각 요소의 앞, 뒤 공백은 자동으로 제거되지 않는다.
- 그래서 각 요소를 `Trim()`으로 정리한 뒤 배열로 만들기 위해 아래처럼 사용한다.
```csharp
string data = "A, B,   C";
var arr = data.Split(',')
              .Select(x => x.Trim())
              .ToArray();
// ["A","B","C"]
```

**동작 설명**
- `var arr = data.Split(',')` → `,` 기준으로 잘라서 문자열 배열 `arr`을 만든다.
- `Select(x => x.Trim())` → 각 요소를 `x`로 지정하여 `x.Trim()`으로 앞/뒤 공백을 제거한다.
- `ToArray()` → 새 묶음을 진짜 배열(`string[]`)로 변환해서 최종`arr`에 담는다.

#### 빈 항목 제거 옵션
- `StringSplitOptions.RemoveEmptyEntries`는 결과에 생긴 빈 문자열`""` 항목을 제거해준다.
- 빈 문자열`""`들이 빠지고 `"A"`, `"B"`만 남는다.
```csharp
string s = "A,,B,";
var arr1 = s.Split(','); 
// ["A", "", "B", ""]

var arr2 = s.Split(',', StringSplitOptions.RemoveEmptyEntries);
// ["A", "B"]
```
### Replace()

#### 문자열(string) 치환
- 특정 문자열을 다른 문자열로 바꾸어 새 문자열을 만들어 준다.
- `"hello world"` 안에서`"world"`라는 부분을 `"C#"`로 바꾸어 **새 문자열로 반환**한다.
```csharp
"hello world".Replace("world", "C#"); // "hello C#"
```
#### 문자(char) 치환
- 원본 문자열 `"1-2-3"` 안에서 `'-'`(하이픈) 문자를 `'/'` 문자로 바꾼 **새 문자열**을 만든다.
```csharp
string result = "1-2-3".Replace('-', '/');
// result: "1/2/3"
```


### 대소문자 변환
```csharp
"AbC".ToLower(); // "abc"
"AbC".ToUpper(); // "ABC"
```

## 6) 포함/검색: Contains, IndexOf, StartsWith, EndsWith

`string s = "Hello C#";  s.Contains("C#");      // true s.StartsWith("He");    // true s.EndsWith("#");       // true s.IndexOf("C#");       // 6 (없으면 -1)`

### ✅ 대소문자 무시하고 비교(실무에서 엄청 씀)

`s.Contains("hello", StringComparison.OrdinalIgnoreCase); // true`

## 7) 부분 추출: Substring / 범위

`string s = "ABCDEFG"; s.Substring(2, 3); // "CDE" (시작인덱스 2, 길이 3)`

### ✅ C# 범위 연산자 (가능하면 이게 편함)

`string s = "ABCDEFG"; s[2..5];  // "CDE" (2 이상 5 미만) s[..3];   // "ABC" s[4..];   // "EFG"`

## 9) 문자열 비교: == vs Equals, StringComparison
