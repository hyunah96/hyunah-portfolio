### 클래스(Class)란?
- 클래스는 데이터(정보) + 기능을 묶어 만든 설계도이다.
- 클래스 자체는 아직 실제 메모리에 만들어진 게 아니라 **정의**만 된 상태다.
#### 클래스 구성 요소
- **데이터**: 필드(Field) / 프로퍼티(Property)
- **기능**: 메서드(Method)
#### 필드(Field)
- 클래스 안에 선언하는 **데이터 저장 변수**(공간)이다.
```csharp
public class Person
{
    public string Name; // 필드
    public int Age;     // 필드
}
```
#### 프로퍼티(Property)
- 필드를 다루는 **안전한 창구(get / set)** 역할이다.
```csharp
public class Person
{
    public string Name { get; set; } = "";
    public int Age { get; set; }
}
```
- 값을 넣을 때 **검증(규칙)** 을 추가하거나, 읽기 전용/쓰기 전용 같은 제어가 가능하다.
```csharp
public class Person
{
    public string Name { get; set; } = "";

    private int _age; // 숨겨둔 필드(백킹 필드)
    public int Age
    {
        get => _age;
        set => _age = value < 0 ? 0 : value;
    }
}
```
#### 클래스 생성
- `public class Person` : 클래스 생성
- `Name`, `Age` : 클래스가 갖는 정보(데이터)
- `SayHello()` : 클래스가 할 수 있는 기능(메서드)
```csharp
using System;

public class Person
{
    // 필드(데이터)
    public string Name;
    public int Age;

    // 메서드
    public void SayHello()
    {
        Console.WriteLine($"이름은 {Name}, 나이는 {Age}");
    }
}
```
### 객체(Object)란?
- 객체는 클래스를 `new` 해서 만든 **실제 데이터** 이다.
- 같은 클래스로 객체는 여러 개 만들 수 있다.
#### 객체 생성
- `new Person()` : 객체 생성
- `p1.Name`, `p1.Age` : 객체 안의 데이터에 값 넣기
- `p1.SayHello()` : 객체의 기능 실행
```csharp
var p1 = new Person(); // Person 객체 1개 생성
p1.Name = "철수";
p1.Age = 25;

p1.SayHello(); // //이름은 철수, 나이는 25
```
#### 객체 여러 개 생성
```csharp
var p1 = new Person();
p1.Name = "철수";
p1.Age = 25;

var p2 = new Person();
p2.Name = "민수";
p2.Age = 20;

p1.SayHello(); // 철수
p2.SayHello(); // 민수
```
### 생성자(Constructor)란?
- 객체가 만들어질 때 자동으로 1번 실행되는 메서드
- 이름이 클래스 이름과 같아야 한다.
- 객체가 생성되자마자 **필드/프로퍼티 초기값을 세팅**할 때 자주 사용한다.
#### 생성자 있는 클래스 생성
- 생성자가 있으면 `new Person()` 처럼 비워서 만들 수 없고, `new Person("철수", 25)` 처럼 **필수 값을 넣어서 생성**해야 한다.
```csharp
public class Person
{
    public string Name;
    public int Age;

    // 생성자: 객체가 만들어질 때 자동 실행
    public Person(string name, int age)
    {
        Name = name;
        Age = age;
    }

    public void SayHello()
    {
        Console.WriteLine($"이름은 {Name}, 나이는 {Age}");
    }
}
```
#### 생성자로 객체 생성
```csharp
var p = new Person("철수", 25); 
p.SayHello();
```
