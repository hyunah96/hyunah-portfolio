### 접근제한자
- **클래스, 필드, 메서드, 프로퍼티**에 **어디서 접근 가능한지** 범위를 정하는 키워드다.
- `public` : 어디서든
- `private` : 클래스 내부만
- `protected` : 클래스 내부 + 자식
- `internal` : 같은 프로젝트
- `protected internal` : 자식 OR 같은 프로젝트
- `private protected` : 자식 AND 같은 프로젝트
#### `public`
- 어디서든 접근 가능하다. (다른 클래스, 다른 프로젝트에서도 가능)
- 외부에 공개하는 기능에 사용한다.
```csharp
class Calculator
{
    // public 이므로 다른 클래스에서 호출 가능
    public int Add(int a, int b)
    {
        return a + b;
    }
}

class Program
{
    static void Main()
    {
        var calc = new Calculator();

        int result = calc.Add(3, 5); // 접근 가능
        Console.WriteLine(result); 
    }
}
```
#### `private`
- 해당 클래스 내부에서만 접근 가능
- 데이터(필드)를 보호하고, 내부 구현을 숨길 때 사용한다.
```csharp
class Account
{
    // private 이므로 다른 클래스에서 접근 불가
    private int _balance = 0;

    // public 이므로 다른 클래스에서 호출 가능
    public void Deposit(int amount)
    {
        if (amount <= 0) return;
        _balance += amount; 
    }

    public int GetBalance()
    {
        return _balance;
    }
}

class Program
{
    static void Main()
    {
        var acc = new Account();

        acc.Deposit(100);                 // 가능
        int b = acc.GetBalance();         // 가능
        Console.WriteLine(b);             // 100

        // acc._balance = 999;            // 불가능 (private이라 접근 불가)
    }
}
```
#### `protected`
- **클래스 내부 + 자식(상속) 클래스**에서 접근 가능하다.
```csharp
class Animal
{
    // protected 자식 클래스에서만 직접 접근 가능
    protected string _name = "동물";

    public void PrintName()
    {
        Console.WriteLine(_name);
    }
}
class Dog : Animal
{
    public void SetName(string name)
    {
        _name = name; // 자식 클래스라서 protected 접근 가능
    }
}
class Program
{
    static void Main()
    {
        var dog = new Dog();
        dog.SetName("초코");
        dog.PrintName(); // "초코"
        
        // dog._name = "바둑이"; // 불가능(외부 클래스에서 protected 접근 불가)
    }
}
```
#### `internal`
- **같은 프로젝트 안에서만** 접근 가능하다.
```csharp
// internal 같은 프로젝트라면 어디서든 접근 가능
internal class Helper
{
    internal static void Log(string msg)
    {
        Console.WriteLine("[LOG] " + msg);
    }
}

class Program
{
    static void Main()
    {
        Helper.Log("같은 프로젝트 내부에서 사용 가능"); // 가능
    }
}
/*
만약 Helper를 다른 프로젝트에서 참조하면
Helper.Log("...");  // 불가능 (internal은 다른 프로젝트에서는 접근 불가)
*/
```
#### `protected internal`
- **자식 클래스(protected) 또는 프로젝트 내부(internal) 둘 중 하나만 만족해도** 접근 가능하다.
```csharp
class Base
{
    // 같은 프로젝트 또는 자식 클래스면 접근 가능
    protected internal int _value = 10;
}

class Child : Base
{
    public void Print()
    {
        Console.WriteLine(_value); // 가능 (자식 클래스)
    }
}

class OtherInSameProject
{
    public void Test()
    {
        var b = new Base();
        Console.WriteLine(b._value); // 가능 (같은 프로젝트)
    }
}

class Program
{
    static void Main()
    {
        new Child().Print();
        new OtherInSameProject().Test();
    }
}
/*
만약 "다른 프로젝트"에서 Base를 참조했다면
- 자식 클래스면 가능 (protected)
- 자식이 아니면 불가능 (internal 조건 깨짐)
*/
```
#### `private protected`
- **같은 프로젝트 안의 자식(상속) 클래스**에서만 접근 가능하다.  
- 조건을 **둘 다** 만족해야 한다.
```csharp
class Base
{
    // private protected: 같은 프로젝트의 자식 클래스만 접근 가능
    private protected int _secret = 777;
}

class Child : Base
{
    public void Show()
    {
        Console.WriteLine(_secret); // 가능 (자식 + 같은 프로젝트)
    }
}

class Other
{
    public void Test()
    {
        var b = new Base();
        // Console.WriteLine(b._secret); // 불가능 (자식 클래스가 아님)
    }
}

class Program
{
    static void Main()
    {
        var c = new Child();
        c.Show(); // 777
    }
}
```
#### 다른 프로젝트에서 접근하기
##### `프로젝트 MyLib`
```csharp
namespace MyLib
{
    public class Base
    {
        protected internal int Value = 10;
    }
}
```
##### `프로젝트 MyApp`
```csharp
using System;
using MyLib;

namespace MyApp
{
    // 프로젝트 MyLib의 Base를 상속하면 protected 조건 만족
    class Derived : Base
    {
        public void Test()
        {
            Console.WriteLine(Value); // 가능
        }
    }
    class Program
    {
        static void Main()
        {
            var b = new Base();
            // Console.WriteLine(b.Value); // Base를 상속하지 않았으므로 불가능
        }
    }
}
```
### 캡슐화란
- 클래스 내부의 데이터(필드)를 **외부에서 직접 수정하지 못하게 숨기고**, 외부에는 **필요한 기능(메서드/프로퍼티)만 공개** 해서 **정해진 방식으로만 접근**하게 만드는 설계 방식이다.
#### 캡슐화가 없는 예제
```csharp
class Account
{
    public int Balance; // 수정 가능
}
class Program
{
    static void Main()
    {
        var acc = new Account();
        acc.Balance = 100;   // 가능
        acc.Balance = -9999; // 가능
        Console.WriteLine(acc.Balance); // -9999
    }
}
```
#### 캡슐화 적용 1
```csharp
class Account
{
    private int _balance = 0; // 외부에서 직접 접근 불가

    public void Deposit(int amount)
    {
        if (amount <= 0) return; // 규칙: 0 이하 입금 금지
        _balance += amount;
    }
    
    public bool Withdraw(int amount)
    {
        if (amount <= 0) return false;   // 규칙: 0 이하 출금 금지
        if (_balance < amount) return false; // 규칙: 잔액 부족이면 출금 불가

        _balance -= amount;
        return true;
    }

    public int GetBalance()
    {
        return _balance; 
    }
}

class Program
{
    static void Main()
    {
        var acc = new Account();

        acc.Deposit(100);                 // 가능
        bool ok = acc.Withdraw(30);      // true
        bool ng = acc.Withdraw(1000);    // false (잔액 부족)

        Console.WriteLine(acc.GetBalance()); // 70

        // acc._balance = -999; // 불가능
    }
}
```
#### 캡슐화 적용2 (`public get`, `private set`)
```csharp
class Account
{
    public int Balance { get; private set; } // 외부에서 읽기(get)가능, 쓰기(set)불가능

    public void Deposit(int amount)
    {
        if (amount <= 0) return;
        Balance += amount;
    }

    public bool Withdraw(int amount)
    {
        if (amount <= 0) return false;
        if (Balance < amount) return false;

        Balance -= amount;
        return true;
    }
}

class Program
{
    static void Main()
    {
        var acc = new Account();

        acc.Deposit(200);
        Console.WriteLine(acc.Balance); // 200 // 가능

        // acc.Balance = 999; // 불가능
    }
}
```
