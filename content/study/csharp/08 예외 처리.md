### 예외 처리란?
- 프로그램 실행 중에 **오류**가 발생했을 때, **프로그램이 바로 죽지 않게** 하거나 **원인을 명확히 전달**하기 위해 사용하는 기능이다.

#### try / catch / finally
- `try`: 예외가 발생할 수도 있는 코드를 수행
- `catch`: 예외가 발생했을 때 코드를 수행
- `finally`: 예외 발생 여부와 상관없이 항상 실행

**try catch 사용한 파일 읽기 예제**
- `catch (Exception ex)`
  `Exception`은 예외의 **최상위 부모 클래스**라서 거의 모든 예외를 다 잡는다.
```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string path = "config.txt";

        try
        {
            string text = File.ReadAllText(path);
            Console.WriteLine("설정 로드 성공: " + text);
        }
        catch (Exception ex)
        {
            Console.WriteLine("설정 로드 중 오류: " + ex.Message);
        }
    }
}
```
**올바른 순서**
- `Exception`이 위에 있으면 아래 `catch`는 도달할 수 없다. 
  구체적인 `catch`를 위에, 넓은 `catch`를 아래에 배치해야 한다.
```csharp
try
{
    // ...
}
catch (FileNotFoundException)
{
    // 파일 없을 때 오류 처리
}
catch (Exception ex)
{
    // 그 외 예상 못한 오류 처리
}

```
**finally 예제**
- `finally`는 **예외 발생 여부와 상관없이 실행**
- 작업 종료 로그, 상태 초기화, 연결 종료 같은 마무리에 자주 쓰인다.
```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string path = "config.txt";

        try
        {
            // config.txt가 있으면 읽어서 출력
            string text = File.ReadAllText(path);
            Console.WriteLine("설정 로드 성공");
        }
        catch (FileNotFoundException)
        {
            // 파일이 없으면 발생하는 예외
            Console.WriteLine("설정 파일이 없어 기본값으로 실행합니다.");
        }
        finally
        {
            // 성공,실패 상관없이 항상 실행
            Console.WriteLine("설정 로드 시도 종료");
        }
    }
}
```
#### throw
- 예외를 직접 발생시키는 구문으로 **명확히 중단**하고 싶을 때 사용한다.
**예제 코드**
```csharp
using System;

class Program
{
    static void Main()
    {
        try
        {
            int age = -1;

            if (age < 0)
                throw new ArgumentException("나이는 0 이상이어야 합니다.");
        }
        catch (ArgumentException ex)
        {
            Console.WriteLine("오류: " + ex.Message);
        }
    }
}
```
