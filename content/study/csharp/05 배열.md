### 1. 배열

- **같은 타입의 값들을 여러 개 묶어서 한 번에 관리하는 자료구조**
- 대괄호 `[]`는 **배열 타입 표시**(또는 인덱스 접근/길이 지정)에 쓰이고, **값 나열**은 `{ }`

#### 1차원 배열

```csharp
int[] a = { 1, 2, 3 };
string[] names = { "철수", "영수" };
```

#### 2차원 배열

```csharp
int[,] grid = {
    {1,2,3 },
    {4,5,6 }
};

Console.WriteLine(grid[0,1]);  //2
Console.WriteLine(grid[1, 2]); //6
Console.WriteLine(grid.GetLength(0));// 행 개수 (2)
Console.WriteLine(grid.GetLength(1));// 열 개수 (3)

```

#### 가변 길이 배열

- **가변배열은 행 개수는 먼저 정하고 열은 각 행마다 마음대로 정할 수 있다**.
- **`int[,]`** → **가변이 아닌 배열**
    - **모든 행이** **같은 열 개수**를 가져야 한다. (2x2 3x3 표 형태)
- **`int[][]`** → **가변 배열 = Jagged Array**
    - 행마다 **열 개수가 달라도 된다.**
- 행 개수도 유동적으로 하고 싶으면 배열보다는 **List<int[]>** 같은 컬렉션을 쓰는 것이 좋다.

```csharp
int[][] b = {
    new int[] { 1, 2, 3 },
    new int[] { 4, 5 },
    new int[] { 6 }
};  //int[][] b = new int[3][]; 과 같은 구조로 초기화 하면서 행 개수를 정한 것

int[][] c = new int[3][];  //행 길이 3으로 생성

c[0] = new int[] { 10, 20, 30 };
c[1] = new int[] { 40, 50 };
c[2] = new int[] { 60 };
```

### int 배열 기본 예시

**선언/초기화**

```csharp
int[] nums = {1, 2, 3}; //축약형
int[] nums = new int[] { 1, 2, 3 }; //명시적
int[] nums = new int[3]; // 3칸짜리 int 배열 (기본값 0,0,0)
```

#### 인덱스(Index)

- 배열의 각 요소는 **인덱스(번호)** 로 접근한다.
- 인덱스 접근은 **대괄호** `[]`

```csharp
int[] scores = {90,80,70,100,85 };

Console.WriteLine(scores[0]);// 90
Console.WriteLine(scores[4]);// 85
```

#### 길이(Length)

- 배열에 들어있는 **요소 개수**는 `Length`로 구한다.
- 마지막 인덱스는 `scores.Length - 1`

```csharp
int[] scores = {90,80,70,100,85};
Console.WriteLine(scores.Length);// 5
```

#### 값 변경

```csharp
int[] scores = {90,80,70,100,85};
scores[0] = 10; //90 → 10
```

### string 배열 기본 예시

**선언/초기화**

```csharp
string[] fruits = { "사과", "바나나", "포도" };
```

#### 인덱스(Index)

- 배열의 각 요소는 **인덱스(번호)** 로 접근한다.
- 인덱스 접근은 **대괄호** `[]`

```csharp
Console.WriteLine(fruits[0]); // 사과
Console.WriteLine(fruits[1]); // 바나나
Console.WriteLine(fruits[2]); // 포도
```

#### 길이(Length)

- 배열에 들어있는 **요소 개수**는 `Length`로 구한다.
- 마지막 인덱스는 `scores.Length - 1`

```csharp
Console.WriteLine(fruits.Length); // 3
Console.WriteLine(fruits[fruits.Length - 1]); // 마지막 요소: 포도
```

#### 배열 길이와 문자열 길이

- `배열.Length` = 배열에 들어있는 **요소 개수**
- `문자열.Length` = 문자열의 **글자 수**

```csharp
string[] words = {"cat","tiger","elephant" };

Console.WriteLine(words.Length);// 3 (요소 개수)
Console.WriteLine(words[0].Length);// 3 ("cat" 글자 수)
Console.WriteLine(words[2].Length);// 8 ("elephant" 글자 수)
```

#### 값 변경

```csharp
string[] fruits = { "사과", "바나나", "포도"};
fruits[0] = "딸기"; //사과 → 딸기
```
