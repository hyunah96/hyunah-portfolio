## `Serialize`, `Deserialize`
>직렬화(Serialize)와 역직렬화(Deserialize)는 데이터의 저장 및 전송을 용이하게 하기 위해 데이터를 변환하는 것이다.

### `Serialize`
- 객체를 파일, 문자열, 바이트처럼 바꿔서 보내기 쉬운 형태로 바꾸는 것
- **객체** → **문자열**
```csharp
SaveFileDialogService.Filter = "Modeling File (.json)|*.json|All Files (*.*)|*.*";
SaveFileDialogService.FilterIndex = 1;

string modelPath = BizFAceService.CurrentModelPath;

var dataModel = CurrentModelData;

var json = JsonSerializer.Serialize(dataModel, jsonOptions);

File.WriteAllText(modelPath, json);
```

첫 번째 괄호
- 메모리에서 가져온 객체로 JSON으로 변환될 대상
두 번째 괄호
- 두번 째 인자는 선택이다. 옵션을 넣을 수도 지정할 수도 있다.
- 변환 규칙, 설정(대소문자 무시, 주석 허용 안 함 등)
```csharp
var json = JsonSerializer.Serialize(dataModel, jsonOptions);
```

`modelPath` 위치에 있는 파일에 `json` **내용 전체를 써서 저장하는 것**
```csharp
File.WriteAllText(modelPath, json);
```
### `Deserialize`
- 파일, 문자열, 바이트를 읽어서 객체 형태로 바꾸는 것
- **문자열 → **객체**
```csharp
OpenFileDialogService.Filter = "Modeling File (.json)|*.json|All Files (*.*)|*.*";
OpenFileDialogService.FilterIndex = 0;
OpenFileDialogService.Multiselect = false;

modelPath = OpenFileDialogService.File.GetFullName();

jsonModel = File.ReadAllText(modelPath);

dataModel = JsonSerializer.Deserialize<FMS>(jsonModel, jsonOptions);
```

**파일 경로(주소)** 가져오기
```csharp
modelPath = OpenFileDialogService.File.GetFullName();
```
`modelPath의 값 : C:\Users\...\Desktop\sample.json`


`modelPath` 위치에 있는 파일을 열어서 **내용 전체를 문자열로 읽는 것**
```csharp
jsonModel = File.ReadAllText(modelPath);
```

`T` (제네릭 타입)
- 만들고 싶은 객체 타입
- `List<Person>`, `Dictionary<string,int>` 등
첫 번째 괄호
- 파일에서 읽어온 문자열로 C#에서 읽고 쓰기 위해 객체로 변환될 대상
두 번째 괄호
- 두번 째 인자는 선택이다. 옵션을 넣을 수도 지정할 수도 있다.
- 변환 규칙, 설정(대소문자 무시, 주석 허용 안 함 등)
```csharp
JsonSerializer.Deserialize<T>(jsonString, options)
```
