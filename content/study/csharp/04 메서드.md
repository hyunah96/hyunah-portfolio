### 1. 메서드

**메서드란?**

작업(기능)을 한 덩어리로 묶어 이름을 붙인 것이다.

#### 반환값이 있는 메서드

```csharp
public static int Add(int a,int b)
{
		int sum = a + b;
		return sum;
}
```

- `public` : 어디서든 호출 가능
- `static` : 객체 없이 바로 호출 가능
- `(int a, int b)` : 매개변수 2개를 받는다.

**호출 예시**

```csharp
int result = Add(3,5);
Console.WriteLine(result);// 8
```

#### 반환값이 없는 메서드 (void)

```csharp
private static void PrintMessage(string message)
{
    Console.WriteLine(message);
}
```

**호출 예시**

```csharp
PrintMessage("안녕하세요");
```

#### bool 반환

```csharp
public static bool IsEven(int number)
{
		return number % 2 == 0; // 짝수면 true, 아니면 false
}
```

**호출 예시**

```csharp
if (IsEven(10))
{
    Console.WriteLine("짝수");
}
```

#### 매개변수와 인자

- **매개변수(Parameter)**: 메서드 정의할 때 받는 변수
- **인자(Argument)**: 호출할 때 실제로 넣는 값

```csharp
int Add(int a,int b)// a, b = 매개변수
{
	return a + b;
}

Add(3,5);// 3, 5 = 인자
```

### 2. 오버로딩(Overloading)

- 메서드 이름은 같아도 **매개변수 종류, 개수**가 다르면 여러 개 만들 수 있다.
- **이름은 같아도 매개변수 모양이 다르면 다른 메서드로 인정된다.**

```csharp
class Calculator
{
    // 1) int 두 개 더하기
    public int Add(int a, int b)
    {
        return a + b;
    }

    // 2) int 세 개 더하기 (매개변수 개수 다름)
    public int Add(int a, int b, int c)
    {
        return a + b + c;
    }

    // 3) double 두 개 더하기 (매개변수 type 다름)
    public double Add(double a, double b)
    {
        return a + b;
    }
}
```

**사용 예시**

```csharp
var cal = new Calculator();

Console.WriteLine(cal.Add(1,2));
Console.WriteLine(cal.Add(1,2,3));
Console.WriteLine(cal.Add(1.5,2.2));
```

### 3. 오버라이딩(Overriding)

- 부모 메서드를 자식 메서드에서 **재정의(덮어쓰기)** 하는 것으로 **부모 메서드**에는 `virtual` 을 **자식 메서드**에는 `override`를 붙인다.
- 기본 동작이 정해져 있지만 다르게 동작해야 할 때 사용한다.
- **오버라이딩**은 덮어쓸 대상이 있어야 하므로, **부모–자식 상속 관계를** 가진 **클래스가 최소 2개 이상** 필요하다.

#### 부모 메서드

```csharp
class Animal
{
public virtual void Sound()
    {
        Console.WriteLine("동물이 소리를 냅니다.");
    }
}
```

#### 자식 메서드

```csharp
class Dog :Animal //왼쪽 자식 오른쪽 부모, Dog가 Animal을 상속받는다는 의미
{
		public override void Sound()
    {
        Console.WriteLine("멍멍");
    }
}

class Cat :Animal  ////왼쪽 자식 오른쪽 부모, Cat이 Animal을 상속받는다는 의미
{
		public override void Sound()
    {
        Console.WriteLine("야옹");
    }
}
```

**호출 예시**

```csharp
Animal dog = new Dog();
Animal cat = new Cat();

dog.Sound();// 멍멍
cat.Sound();// 야옹
```

#### **반환 오버라이딩**

```csharp
class Animal
{
    public virtual int GetLegCount()
    {
        return 0;
    }
}

class Dog : Animal
{
    public override int GetLegCount()
    {
        return 4;
    }
}
```

**호출 예시**

```csharp
Animal animal = new Animal();
Console.WriteLine(animal.GetLegCount()); // 0

Dog dog = new Dog();
int legs = dog.GetLegCount();
Console.WriteLine(legs); // 4
```

### 4. optional / named parameter

#### Optional Parameter (선택 매개변수)

- 메서드 매개변수에 **기본값을 미리 정해두는 것으로** 호출할 때 그 값을 **안 넣어도 자동으로 기본값**이 들어간다.
- **규칙** : **Optional Parameter(선택 매개변수)**는 **뒤쪽**에 둬야 한다.

**규칙**

```csharp
void Test(int a, int b = 1) 
void Test(int a = 1, int b) //규칙에 어긋남
```

```csharp
static void PrintMessage(string message, int count = 1)
{
    for (int i = 0; i < count; i++)
    {
        Console.WriteLine(message);
    }
}
```

**호출 방법**

```csharp
PrintMessage("안녕");      // count를 넣지 않으면 기본값 1이 들어감
PrintMessage("안녕", 3);   // count에 3을 넣음
```

### 5. Named Parameter (이름 지정 인자)

- 메서드를 호출할 때 **이 값은 어떤 매개변수에 들어가는 값인지 이름을 붙여서 호출**한다.

```csharp
static void PrintInfo(string name, int age, string city)
{
    Console.WriteLine($"{name}, {age}, {city}");
}
				 //매개변수이름: 값
PrintInfo(age: 20, city: "Seoul", name: "Kim"); //순서를 바꿔도 정확하게 들어감
```

### 6. ref

- **기존 변수**를 그대로 가져와서 **수정해야 할 때 사용한다.**
- 호출 전에 **반드시 값이 있어야 한다.**

```csharp
void AddOne(ref int x)
{
    x += 1;
}

int n =10;
AddOne(ref n);// n = 11

// 매개변수를 ref int x로 받으면 메서드 안의 x는 호출한 쪽 변수(n)의 별명처럼 동작
// 그래서 x로 인해 값이 바뀌면 원래 변수(n)도 같이 바뀜
```

### 7. out

- 메서드가 **값을 만들어서 밖으로 꺼내줄 때** **사용한다.**
- 호출 전에 값이 없어도 되지만 대신 메서드 내부에서 **반드시 값을 대입해야 한다.**

```csharp
void MakeTen(out int x)
{
    x = 10; // out은 여기서 반드시 값을 넣어줘야 함
}

int a;             // 초기화 안 해도 됨
MakeTen(out a);
Console.WriteLine(a); // 10
```

**가장 많이 쓰는 패턴**

- 성공하면 `true`,`age`에 결과 넣어준다.
- 실패하면 `false` 이지만 `age`에 **값을 넣어줘야 한다.**

```csharp
bool TryGetAge(string s, out int age)
{
    if (s == "20")
    {
        age = 20;
        return true;
    }

    age = 0;      // false여도 out 값은 꼭 대입해야 함
    return false;
}

if (TryGetAge("20", out int myAge))
{
    Console.WriteLine($"성공: {myAge}");
}
else
{
    Console.WriteLine("실패");
}

```

### 8. params

- **인자를 몇 개를 주든** 함수가 **배열로 받아서 처리할 때 사용한다.**

```csharp
using System;

class Program
{
    static int Sum(params int[] numbers)
    {
        int total = 0;

        foreach (int n in numbers)
            total += n;

        return total;
    }

    static void Main()
    {
        int[] arr = { 2, 4, 6 };
        Console.WriteLine(Sum(arr));      // 12  (인자를 배열로도 줄 수 있음)

        Console.WriteLine(Sum(1, 2, 3));  // 6  
    }
}
```

### 9. 리팩토링

- 코드의 구조를 더 읽기 쉽고, 수정, 확장, 테스트하기 좋게 정리하는 작업

**리팩토링 연습 (간단 계산기)**

```csharp
using System;

namespace ConsoleApp
{
    internal class Program
    {
        static void Main(string[] args)
        {
            Calculator calculator = new Calculator();
            calculator.Run();
        }
        class Calculator
        {
            //초기 실행
            public void Run()
            {
                int firstInput = ReadInt("첫번째 숫자를 입력해주세요");
                string op = ReadOperator("연산자를 입력해주세요");
                int secondInput = ReadInt("두번째 숫자를 입력해주세요");
                int result = Calculate(firstInput, op, secondInput);
                Console.WriteLine("값은 " + result);
            }
            //숫자 확인
            public int ReadInt(string msg)
            {
                while (true) {
                Console.WriteLine(msg);
                if (int.TryParse(Console.ReadLine(), out int num))
                    return num;
                Console.WriteLine("올바른 숫자를 입력해주세요");
                    continue;
                }
            }
            //연산자 확인
            public string ReadOperator(string msg)
            {
                while (true)
                {
                    Console.WriteLine(msg);
                    string? op = Console.ReadLine();

                    if (!string.IsNullOrWhiteSpace(op))
                    {
                        if (op == "+" || op == "-" || op == "*" || op == "/")
                            return op;
                    }
                    continue;
                }
            }
            //계산
            public int Calculate(int firstInput, string op, int secondInput) {

                int result = op switch
                {
                    "+" => firstInput + secondInput,
                    "-" => firstInput - secondInput,
                    "*" => firstInput * secondInput,
                    "/" => firstInput / secondInput,
                    _ => 0
                };
                return result;
            }
        }
    }
}
```
