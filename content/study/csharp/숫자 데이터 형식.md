## 숫자 데이터 형식
C#은 기본 데이터 형식 15가지 중 **12가지를 숫자 데이터 형식**으로 제공한다.  
이 숫자 형식들은 다시 **정수 계열**, **부동 소수점 계열**, **소수 계열**로 나뉜다.
### 정수 계열 형식
정수 계열 형식은 **정수 데이터를 저장**하기 위한 타입이다.  
정수형은 타입마다 **크기(byte)** 와 **표현 가능한 범위**가 다르며, 저장하려는 값의 범위를 고려해 적절한 타입을 선택하면 **메모리를 효율적으로** 사용할 수 있다.

| 데이터 형식   | 설명       | 크기(byte)     | 담을 수 있는 값의 범위  |
| -------- | -------- | ------------ | -------------- |
| `byte`   | 부호 없는 정수 | 1byte(8bit)  | 0~255          |
| `sbyte`  | 정수       | 1byte(8bit)  | ~128~127       |
| `short`  | 정수       | 2byte(16bit) | -32,768~32,767 |
| `ushort` | 부호 없는 정수 | 2byte(16bit) | 0~65,535       |
| `int`    | 정수       | 4byte(32bit) | -21억~21억       |
| `uint`   | 부호 없는 정수 | 4byte(32bit) | 0~42억          |
| `long`   | 정수       | 8byte(64bit) | 매우 큼           |
| `ulong`  | 부호 없는 정수 | 8byte(64bit) | 매우 큼           |
| `char`   | 유니코드 문자  | 2byte(16bit) |                |
##### 예제코드
```csharp
static void Main(string[] args)
{
    sbyte a = -10;
    byte b = 40;

    Console.WriteLine($"a = {a}, b = {b}");

    short c = -30000;
    ushort d = 60000;

    Console.WriteLine($"c = {c}, d = {d}");

    int e = -1000_0000;
    uint f = 3_0000_0000;

    Console.WriteLine($"e = {e}, f = {f}");

    long g = -5000_0000_0000;
    ulong h = 200_0000_0000_0000_0000;

    Console.WriteLine($"g = {g}, h = {h}");
}
```
##### 실행 결과
```csharp
a = -10, b = 40
c = -30000, d = 60000
e = -10000000, f = 300000000
g = -500000000000, h = 2000000000000000000
```
##### `_`(언더바)
- 숫자 사이에 들어가는 `_`는 **숫자 구분자** 이다.  
- 큰 숫자를 작성할 때 **자리수를 읽기 쉽게 끊어주는 용도**이며, 실제 값에는 **아무 영향도 없다.**
- 아래는 모두 동일한 값이다.
- `10000000` == `10_000_000`
- `300000000` == `300_000_000`

### 2진수, 10진수, 16진수 리터럴
c#은 2진수 리터럴을 위해 0b , 16진수 리터럴을 위해 0X(또는 0x) 접두사를 제공한다. 
##### 예제코드
```csharp
static void Main(string[] args)
{
    byte a = 240;           //10진수 리터럴 
    Console.WriteLine($"a = {a}");

    byte b = 0b1111_0000;   //2진수 리터럴 
    Console.WriteLine($"b = {b}");

    byte c = 0XF0;          //16진수 리터럴 
    Console.WriteLine($"c = {c}");

    uint d = 0x1234_abcd;   //16진수 리터럴 
    Console.WriteLine($"d = {d}");
}
```
##### 실행 결과
```csharp
a = 240
b = 240
c = 240
d = 305441741
```

### 오버플로우, 언더플로우
데이터 형식의 크기를 넘어선 값을 담았을 때 발생하는 현상을 **오버플로우(overflow)**, 최저값보다 작은 데이터를 담았을 때 발생하는 현상을 **언더플로우(underflow)** 라고 한다.
