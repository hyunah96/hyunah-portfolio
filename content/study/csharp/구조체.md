### 구조체
- **사용자 정의 데이터 유형**으로`int`, `double`, `bool` 같은 기본적으로 제공되는 변수 유형이 아닌 새로운 유형, 여러가지 유형을 사용하기 위해 사용자가 직접 만들어 사용하는 것이다.
- C#에서 구조체는 **값 형식**의 데이터 형식이다.
#### C# 구조체 특징
- 필드(변수)를 가질 수 있다.
- 메서드(method)를 가질 수 있다.
- 속성(property)을 가질 수 있다.
- 생성자를 정의할 수 있다.
- `new` 연산자로 `struct` 객체를 생성할 수 있다.
- 구조체는 상속을 지원하지 않는다.
- 구조체는 기본(defalut) 생성자를 가질 수 없습니다.
#### 구조체 정의하기
- 구조체는 `struct` 키워드로 정의한다.
- `{ }`안에 멤버 변수(필드)들을 정의
- 두개 이상의 멤버(변수)가 있는 새로운 데이터 형식을 정의한다.
```csharp
struct Student
{
    public string name;
    public int std_num;
    public int age;
}
```
#### 구조체 사용하기
- 일반 변수처럼 구조체 변수를 선언한 후`.(점)`을 통해 접근한다.
```csharp
using System;

struct Student
{
    public string name;
    public int std_num;
    public int age;
}

class Program
{
    static void Main()
    {
        Student std;   // 구조체 변수 선언
        Student std2;

        std.name = "김현아";
        std.std_num = 201908017;
        std.age = 26;

        std2.name = "김철수";
        std2.std_num = 201811099;
        std2.age = 27;

        Console.WriteLine("Student 1 name : {0}", std.name);
        Console.WriteLine("Student 1 std_num : {0}", std.std_num);
        Console.WriteLine("Student 1 age : {0}", std.age);

        Console.WriteLine("Student 2 name : {0}", std2.name);
        Console.WriteLine("Student 2 std_num : {0}", std2.std_num);
        Console.WriteLine("Student 2 age : {0}", std2.age);
    }
}
```
#### 구조체는 값 형식(Value Type)
- 구조체는 값을 참조하는 게 아니라 값을 **복사**한다.
- p2를 바꿔도 p1은 그대로이다.
```csharp
using System;

struct Point
{
    public int X;
    public int Y;
}

class Program
{
    static void Main()
    {
        Point p1 = new Point { X = 1, Y = 2 };
        Point p2 = p1;   // 값 복사

        p2.X = 100;

        Console.WriteLine(p1.X); // 1
        Console.WriteLine(p2.X); // 100
    }
}
```
