### 문제 설명
정수 배열 `numbers`가 매개변수로 주어집니다. `numbers`의 각 원소에 두배한 원소를 가진 배열을 return하도록 solution 함수를 완성해주세요.

---
### 제한사항
- -10,000 ≤ `numbers`의 원소 ≤ 10,000
- 1 ≤ `numbers`의 길이 ≤ 1,000
---
### 입출력 예
|numbers|result|
|---|---|
|[1, 2, 3, 4, 5]|[2, 4, 6, 8, 10]|
|[1, 2, 100, -99, 1, 2, 3]|[2, 4, 200, -198, 2, 4, 6]|
##### 입출력 예 설명

입출력 예 #1
- [1, 2, 3, 4, 5]의 각 원소에 두배를 한 배열 [2, 4, 6, 8, 10]을 return합니다.

입출력 예 #2

- [1, 2, 100, -99, 1, 2, 3]의 각 원소에 두배를 한 배열 [2, 4, 200, -198, 2, 4, 6]을 return합니다.
### Solution.cs
```csharp
using System;

public class Solution {
    public int[] solution(int[] numbers) {
        int[] answer = new int[numbers.Length];
        for(int i=0; i<numbers.Length; i++){
            answer[i] = numbers[i] * 2;
        }
        return answer;
    }
}
```
### 풀이 기록 정리
- C# 배열 길이는`Length` (L 대문자) 를 사용한다. (`numbers.Length`)
- 배열은 **고정 길이**라서 `new int[] {}` 처럼 **빈 배열**로 만들면 길이가 0으로 고정되고, 그 상태에서 `answer[i] = ...`처럼 인덱스로 넣으면 **범위를 벗어나 에러**가 난다.
- 미리 `new int[numbers.Length]`로 **크기를 맞춰 생성**한 뒤, `for`문으로 채운다.
- 아니면 `List<int>` **가변 길이 배열을** 써도 된다.
##### `List<T>`
```csharp
using System;
using System.Collections.Generic;

public class Solution {
    public int[] solution(int[] numbers) {
        List<int> list = new List<int>();

        for (int i = 0; i < numbers.Length; i++) {
            list.Add(numbers[i] * 2);
        }
        return list.ToArray(); // List -> int[] 변환
    }
}
```
- 반환 타입은 `int[]`로 고정되어 있어서 `public int[] solution(int[] numbers)` `list.ToArray()`로 `List<int>`를 `int[]`로 변환해서 반환 타입을 맞춘다.
- `list.ToArray()`는 말 그대로 `List`를 배열(Array)로 변환해서 새로 만들어 주는 메서드
```csharp
List<int> list = new List<int>() { 2, 4, 6 };
int[] arr = list.ToArray();   // arr == [2, 4, 6]
```
