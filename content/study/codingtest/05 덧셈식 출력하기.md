### 문제 설명
두 정수 `a`, `b`가 주어질 때 다음과 같은 형태의 계산식을 출력하는 코드를 작성해 보세요.

---
### 제한사항
- 1 ≤ `a`, `b` ≤ 100
---
### 입출력 예

**입력 #1**
```text
4 5
```
**출력 #2**
```text
4 + 5 = 9
```
### Solution.cs
```csharp
using System;

public class Example
{
    public static void Main()
    {
	    string input = Console.ReadLine();
		var arr = input.Split(" ");
		int.TryParse(arr[0], out int a);
		int.TryParse(arr[1], out int b);
		Console.WriteLine($"{a} + {b} = {a + b}");
    }
}
```
### 개선 포인트
```csharp
var input = Console.ReadLine().Split();
int a = int.Parse(input[0]);
int b = int.Parse(input[1]);
Console.WriteLine($"{a} + {b} = {a + b}");
```
-  `Split()` 사용
	인자가 없는 Split()는 스페이스나 탭 같은 공백류를 구분자로 인식하기 때문에 `Split(" ")`를 하지않아도 된다.
- `var input = Console.ReadLine().Split()` 입력 처리 방식 단순화
	기존 방식은 입력 문자열을 한 번 변수에 저장한 뒤 다시 `Split()`을 호출했지만 한 줄로도 동일하게 처리할 수 있다. `Console.ReadLine()`의 반환값에 바로 `Split()`을 이어서 호출하면 된다.
