### 문제 설명
영어 알파벳으로 이루어진 문자열 `str`이 주어집니다. 각 알파벳을 대문자는 소문자로 소문자는 대문자로 변환해서 출력하는 코드를 작성해 보세요.

---
### 제한사항
- 1 ≤ `str`의 길이 ≤ 20
- `str`은 알파벳으로 이루어진 문자열입니다.
---

### 입출력 예

**입력 #1**
```text
aBcDeFg
```
**출력 #2**
```text
AbCdEfG
```
### Solution.cs
```csharp
using System;

public class Example
{
    public static void Main()
    {
        string input = Console.ReadLine();

        char[] arr = input.ToCharArray();
        char[] newArr = new char[arr.Length];

        for (int i = 0; i < arr.Length; i++)
        {
            if (char.IsUpper(arr[i]))
                newArr[i] = char.ToLower(arr[i]);
            if (char.IsLower(arr[i]))
                newArr[i] = char.ToUpper(arr[i]);
        }
        Console.WriteLine(newArr);
    }
}
}
```
### 풀이 기록 정리
1) `char[] arr = input.ToCharArray()`
	- `input`에 들어있는 문자열을 **문자(char) 단위로 쪼개서** `char[]` 배열로 만든다.
	- `"aBcDe"` → `['a', 'B', 'c', 'D', 'e']`
	> 참고) `char[]`는 출력할 때 배열 안의 문자들을 이어붙인 문자열처럼 보여줘서 결과가 `"aBcDe"`처럼 출력된다. 하지만 실제로는 `arr[0]`, `arr[1]` 각 칸에 char가 따로 저장되어 있다.

 2) `char.IsUpper`, `char.IsLower`
	 - `char.IsUpper(arr[i])` : 해당 문자가 **대문자(A~Z)면 `true`
	 - `char.IsLower(arr[i])` : 해당 문자가 **소문자(a~z)면 `true`
    
	 - 대/소문자를 판별한 뒤, 대문자면 `char.ToLower()`로 소문자로 변환, 소문자면 `char.ToUpper()`로 대문자로 변환한다.
	 - 변환 결과를 `newArr[i]`(또는 `arr[i]`)에 저장한다.

### 개선 포인트
1) `if` 두 개 → `else if`
	 -  대문자/소문자는 동시에 참이 될 수 없으므로, 첫 조건이 참이면 두 번째 조건은 볼 필요가 없다.(`if` 두 개를 쓰면 매번 두 번 검사하게됨)
2) `newArr` 없이 `arr` 자체를 수정해도 된다.
	 - 원본 보존이 낫다고 생각해서 새로운 배열을 생성했지만 단순 변환이면 `arr[i]`에 바로 덮어쓰는 것이 깔끔하다.
	 - `StringBuilder`도 가능하지만 성능 차이는 거의 의미 없다.
	   (`StringBuilder`는 문자열을 반복해서 이어붙일 때(길이가 길 때) 성능상 유리하다.)
