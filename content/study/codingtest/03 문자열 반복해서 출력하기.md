### 문제 설명
문자열 `str`과 정수 `n`이 주어집니다.  
`str`이 `n`번 반복된 문자열을 만들어 출력하는 코드를 작성해 보세요.

---

### 제한사항
- 1 ≤ `str`의 길이 ≤ 10
- 1 ≤ `n` ≤ 5
---

### 입출력 예

**입력 #1**
```text
string 5
```
**출력 #2**
```text
stringstringstringstringstring
```
### Solution.cs
```csharp
using System;

public class Example
{
    public static void Main()
    {
        string[] input = Console.ReadLine().Split(' ');
        string str = input[0];
        int.TryParse(input[1], out int n);

        for (int i = 1; i <= n; i++)
        {
            Console.Write(str);
        }
    }
}

```
### 풀이 기록
`string[] input = Console.ReadLine().Split(' ')`
- `Console.ReadLine()`은 문자열 1개를 반환하지만 `Split(' ')`의 반환 값은 분리된 문자열들을 담은 <br>문자열 배열이기 때문에`string []`으로 받아야 한다.

`int.TryParse(input[1], out int n)`
- 반복 횟수 `n`을 숫자로 사용하려면 문자열을 `int)` 로 변환해야 하는데 여기서 문자열을 정수로 바꾸는 방법은 <br>대표적으로 `int.Parse()`와 `int.TryParse()`가 있다.
- `int.Parse`는 변환에 성공하면 `int`를 반환하지만, 입력된 값이 숫자가 아니면 예외가 발생한다.
- `int.TryParse`는 변환이 가능하면 `true`, 불가능하면 `false`를 반환하고, 예외를 발생시키지 않아서 <br>더 안전한 방법이라고 생각했다.
