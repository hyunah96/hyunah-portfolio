### 문제 설명
최빈값은 주어진 값 중에서 가장 자주 나오는 값을 의미합니다. 정수 배열 `array`가 매개변수로 주어질 때, 최빈값을 return 하도록 solution 함수를 완성해보세요. 최빈값이 여러 개면 -1을 return 합니다.

---
### 제한사항
- 0 < `array`의 길이 < 100
- 0 ≤ `array`의 원소 < 1000

---
### 입출력 예
| array              | result |
| ------------------ | ------ |
| [1, 2, 3, 3, 3, 4] | 3      |
| [1, 1, 2, 2]       | -1     |
| [1]                | 1      |
##### 입출력 예 설명

**입출력 예 #1**
- [1, 2, 3, 3, 3, 4]에서 1은 1개 2는 1개 3은 3개 4는 1개로 최빈값은 3입니다.
**입출력 예 #2**
- [1, 1, 2, 2]에서 1은 2개 2는 2개로 최빈값이 1, 2입니다. 최빈값이 여러 개이므로 -1을 return 합니다.
**입출력 예 #3**
- [1]에는 1만 있으므로 최빈값은 1입니다.
### Solution.cs
```csharp
using System;
using System.Linq;
using System.Collections.Generic;

public class Solution
{
    public int solution(int[] array)
    {
        int max = 0;
        int maxNum = 0;
        int[] disArr = array.Distinct().ToArray();

        foreach (int n in disArr)
        {
            int count = array.Count(v => v == n);

            if (count > max)
            {
                max = count;
                maxNum = n;
            }
            else if (count == max)
            {
                maxNum = -1;
            }
        }
        return maxNum;
    }
}
```

- 반복, 제어문으로 하니까 코드가 너무너무너무x30 길어서 다른 사람 풀이과정을 봤다. 
- LINQ 최고네..

```csharp
int[] disArr = array.Distinct().ToArray();
```
- `array.Distinct()` : 중복 제거해서 배열 `int[] disArr`에 담는다.
- 참고: LINQ `Distinct()` 결과는 배열이 아니라 문자열 나열이다. ex)`[1,1,2,2,3]`
```csharp
foreach(int n in disArr)

```
- 중복 제거된 숫자를 꺼낸다.
```csharp
int count = array.Count(v => v == n);
```
- LINQ `array.Count()`는 원소의 개수를 세는 문법으로 `array.Length`랑 같은 셈인데 괄호 안에 조건을 걸 수 있다. `array.Count(조건 성립 된 애만 세라)`
- 여기서는 `v => v == n` 이니까 원본 `array`를 돌면서 `v == n`이 성립하는 값의 개수를 센다.
- `v`는 `array`를 하나씩 돌 때 현재 꺼낸 값을 임시로 부르는 이름이다.
