### 문제 설명
문자열 `str`이 주어질 때, `str`을 그대로 출력하는 코드를 작성해 보세요.

---

### 제한사항
- `1 ≤ str`의 길이 `≤ 1,000,000`
- `str`에는 공백이 없으며, 첫째 줄에 한 줄로만 주어집니다.

---

### 입출력 예

**입력 #1**
```text
HelloWorld!
```
**출력 #2**
```text
HelloWorld!
```
### Solution.cs
```csharp
using System;

public class Example
{
    public static void Main()
    {
		string str;
        str = Console.ReadLine();
        Console.WriteLine(str);
    }
}
```
