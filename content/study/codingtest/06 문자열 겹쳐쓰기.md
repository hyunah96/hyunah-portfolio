### 문제 설명
문자열 `my_string`, `overwrite_string`과 정수 `s`가 주어집니다. 문자열 `my_string`의 인덱스 `s`부터 `overwrite_string`의 길이만큼을 문자열 `overwrite_string`으로 바꾼 문자열을 return 하는 solution 함수를 작성해 주세요.

---
### 제한사항
- `my_string`와 `overwrite_string`은 숫자와 알파벳으로 이루어져 있습니다.
- 1 ≤ `overwrite_string`의 길이 ≤ `my_string`의 길이 ≤ 1,000
- 0 ≤ `s` ≤ `my_string`의 길이 - `overwrite_string`의 길이

---
### 입출력 예

**입력 #1**

| my_string        | overwrite_string | s   | result           |
| ---------------- | ---------------- | --- | ---------------- |
| "He11oWor1d"     | "lloWorl"        | 2   | "HelloWorld"     |
| "Program29b8UYP" | "merS123"        | 7   | "ProgrammerS123" |
##### 입출력 예 설명

**입출력 예 #1**

- 예제 1번의 `my_string`에서 인덱스 2부터 `overwrite_string`의 길이만큼에 해당하는 부분은 "11oWor1"이고 이를 "lloWorl"로 바꾼 "HelloWorld"를 return 합니다.

**입출력 예 #2**

- 예제 2번의 `my_string`에서 인덱스 7부터 `overwrite_string`의 길이만큼에 해당하는 부분은 "29b8UYP"이고 이를 "merS123"로 바꾼 "ProgrammerS123"를 return 합니다.
### Solution.cs
```csharp
using System;

public class Example
{
    public static void Main()
    {
        string my_String = Console.ReadLine();          
        int s = int.Parse(Console.ReadLine());        
        string overwrite_String = Console.ReadLine(); 
        string result = myString
            .Remove(s, overwrite_String.Length)
            .Insert(s, overwrite_String);

        Console.WriteLine(result);
    }
}
```
### 풀이 기록 정리
- `s` 위치부터 `overwriteString.Length` 만큼 `Remove(s, overwriteString.Length)`로 먼저 제거한다.
- `Insert(s, overwriteString)`로 새 문자열을 삽입하여 `overwrite_String`에 덮어쓴다.
- 최종적으로 생성된 문자열을 출력한다.
